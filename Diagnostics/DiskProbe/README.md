# DiskProbe

디스크 I/O 항목을 만들기 전에, 관리자 권한 없이 디스크별 I/O 통계를 읽을 수 있는지와 그 값의 뜻을 확인한다.

- 출처: IORegistry의 `IOBlockStorageDriver` → `Statistics` (활성 상태 보기·`iostat`과 같은 출처). 부팅 뒤 누적 바이트·작업 수·걸린 시간(ns)·오류·재시도
- 확인할 것
  - 어떤 디스크가 잡히는지(내장 SSD, 외장, 디스크 이미지), 내장·외장·가상을 구분할 속성
  - 디스크 이미지의 쓰기가 실제 디스크(disk0)에도 같이 세어지는지(중복 합산)
  - 부하에서 바이트 증가량이 실제로 읽고 쓴 양과 맞는지
  - '걸린 시간 합 ÷ 구간'이 활성 시간 %로 쓸 만한지: 한 번에 하나(스레드 1)와 여러 개 동시(8·32)에서 100%를 넘는지
  - 평균 응답 시간(걸린 시간 ÷ 작업 수)이 부하에 따라 말이 되는지
  - 한 번 읽는 데 걸리는 시간
- 실행: `./measure.sh` (외장 디스크도 재려면 `./measure.sh /Volumes/<이름>`). 시험 파일은 끝나면 지운다
- 결과: `results/<시각>/` — `disks.txt`, `disks-with-image.txt`, `samples.tsv`(1초마다 디스크별 통계), `phases.tsv`(단계별 시각·실제로 읽고 쓴 양)
- SMART: `./measure-smart.sh` — SMART를 지원하는 디스크의 NVMe SMART 로그(512바이트)를 읽고, 1 GiB를 쓴 뒤 다시 읽어 총 쓰기량 증가를 비교한다(`smart_probe.c`)

## 결과 (2026-11-03, MacBookPro18,1, macOS 27.2)

### I/O 통계 (`results/20261103-220158`)
- 잡힌 디스크: disk0 내장 SSD(`Apple Fabric`, `Internal`), disk10 내장 SD 카드 리더(`Secure Digital`, `Internal`), disk4·6·8 디스크 이미지(늘 붙어 있음), 시험용 디스크 이미지 disk11. 디스크 이미지는 `Physical Interconnect`가 `Virtual Interface`
- 바이트 증가량은 실제로 읽고 쓴 양과 0.1% 안: 순차 쓰기 8,590 대 8,599 MB, 순차 읽기 52,655 대 52,656 MB, 무작위 읽기 32개 10,655 대 10,659 MB
- 내장 SSD: 순차 읽기 3.5 GB/s, 순차 쓰기 3.1~3.3 GB/s, 4 KiB 무작위 읽기 동시 1·8·32개 57·455·710 MB/s
- 걸린 시간 합 ÷ 구간 = 평균 동시 요청 수: 동시 1개 0.90~0.96, 8개 6.9, 32개 26.9. 100%를 넘으므로 활성 시간 %로 쓸 수 없음. 100%에서 자르면 짧게 몰리는 부하에서 실제보다 높게 나옴
- 가만히 있어도 거의 매초 작업이 몇 개씩 있어서 '사용 중/쉬는 중'은 늘 사용 중
- 평균 응답 시간(걸린 시간 ÷ 작업 수): 4 KiB 무작위 0.064 ms(동시 1) → 0.156 ms(동시 32), 1 MiB 순차 읽기 0.28 ms, 쓰기 0.18 ms. 초당 작업이 1~3개뿐인 구간은 0.8~1.3 ms로 튐
- `Latency Time (Read/Write)`는 늘 0, 오류·재시도는 0
- 디스크 이미지에 쓴 50 MB가 disk0에도 53 MB로 세어짐(중복)
- 디스크 하나 읽는 데 20~90 µs

### SMART (`results/smart-20261103-221120`)
- 관리자 권한 없이 읽힘(`IONVMeSMARTInterface`의 `SMARTReadData`). 지원하는 디스크는 disk0 하나(`NVMe SMART Capable`), SD 카드·디스크 이미지는 지원 안 함
- 1 GiB(1,073.7 MB)를 쓴 뒤 `data_units_written`이 2,121 단위(× 512,000 바이트 = 1,086 MB) 늘어남 → 맞음(나머지는 그동안의 시스템 쓰기)
- 값: 수명 사용 4%, 예비 공간 100%(기준 99%), 총 읽기 118.8 TB, 총 쓰기 57.6 TB, 사용 시간 1,489시간, 전원 켠 횟수 560, 비정상 종료 16, 매체 오류 0, 오류 기록 0, 위험 경고 없음, 온도 303 K(30 °C)
- `controller_busy_minutes`는 0(이 SSD는 알려 주지 않음). 고온 시간 2개는 0
- 플러그인 만들기 5~8 ms, 한 번 읽기 0.35~1.4 ms → 한 번 만들어 두고 다시 씀
