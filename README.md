# MonitorTool

macOS 메뉴 막대에 상주하는 개인용 시스템 모니터링 앱입니다. 단축키나 메뉴 막대 아이콘으로 화면 오른쪽에 실시간 패널을 꺼내 보고, 알림 센터에서도 같은 수치를 확인하는 것을 목표로 합니다. [Monit](https://mmonit.com/widget/)의 빠르게 확인하는 사용 경험을 참고했습니다.

> 개발 중입니다. 설계는 [docs/PROJECT_DESIGN.md](docs/PROJECT_DESIGN.md)에 있고, 단계별 작업 과정을 커밋 기록으로 남기고 있습니다.

## 보여줄 정보

| 항목 | 기본 화면 | 펼치면 |
|---|---|---|
| CPU | E-core·P-core 사용률, CPU 전력 W | E/P 사용률·전력 그래프, 코어별 정보 |
| GPU | 사용률, GPU 전력 W | 사용률·전력 그래프 |
| ANE (Neural Engine) | 사용 중 여부, 전력 W (사용률 %는 macOS에서 잴 수 없어 '측정 불가'로 표시) | 전력·메모리 트래픽 그래프, 켜져 있을 때의 ANE 온도, 측정 범위 설명 |
| RAM | 사용량/전체, 사용률, 메모리 트래픽(합계와 CPU·GPU·ANE별 GB/s) | 사용량·트래픽 그래프, 읽기·쓰기, 메모리 압력, 압축, 스왑 |
| 온도·팬 | CPU·GPU 최고 온도, 팬별 RPM | 센서별 온도, 팬별 RPM 그래프 |
| 배터리 | 잔량, 충전/방전 상태, 순전력 W, 예상 시간 | 순전력 그래프, 성능 상태, 최대 용량, 사이클 수 |
| 네트워크 | 업로드·다운로드 속도, 오늘 누적 | 그래프, 오늘·이번 실행 누적, 인터페이스별 수치 |

측정 전이거나 읽지 못한 값은 0으로 채우지 않고 상태(준비 중·미지원·권한 필요·오류·오래됨)로 표시합니다.

## 화면

- **실시간 패널**: 메뉴 막대 아이콘이나 단축키(기본 fn + Space, 설정에서 끄거나 직접 정한 조합으로 바꿀 수 있음)로 화면 오른쪽에서 꺼냅니다. 맨 위 카드에 CPU·GPU·ANE를 나란히 보여주고, 수치를 누르면 그 아래로 그래프와 상세 정보가 펼쳐집니다. 막대와 그래프 색은 설정에서 항목마다 일곱 가지 중 고를 수 있습니다.
- **알림 센터 위젯**: 핵심 수치를 보여주고, 버튼을 누르면 같은 크기 안에서 상세(그래프) 화면으로 바뀝니다. 원래는 누르면 위젯 높이가 늘어나는 방식을 원했지만, 이를 위한 구형 Today 확장이 macOS 27에서 등록되지 않는 것을 [진단 앱](Diagnostics/TodayWidgetProbe)으로 확인하고 이 방식으로 바꿨습니다. 위젯 화면은 본 프로그램을 완성한 뒤 설계합니다(큰·중간 크기).

## 처음 실행할 때

1. Xcode에서 **MonitorTool** 스킴으로 실행합니다. 보조 프로그램(`MonitorToolHelper`)은 함께 빌드되어 앱 안에 들어갑니다. 개인 팀으로 서명하므로 Xcode에 Apple ID가 로그인되어 있어야 합니다.
2. 패널 아래 **CPU·ANE 전력: 보조 프로그램 허용하기**를 누르면 시스템 설정의 로그인 항목 화면이 열립니다. '백그라운드에서 허용'에서 MonitorTool을 켜면 CPU·ANE 전력이 나타납니다.
3. 끄려면 설정 창의 **보조 프로그램** 탭에서 '끄기'를 누릅니다. 앱을 지우기 전에도 꺼 두세요.
4. fn + Space로 패널을 열려면 처음 실행할 때 뜨는 macOS 창(또는 설정 창 '일반'의 **허용하기**)에서 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용의 MonitorTool을 켭니다. 권한 없이 쓰려면 설정 창 '일반'에서 '직접 정한 조합'(기본 ⌃⌥M)을 고르고, 단축키가 필요 없으면 스위치로 끕니다.

## 설계 원칙

- 수집은 메인 앱 한 곳에서 하고, 패널과 위젯은 같은 데이터를 봅니다.
- 관리자 권한이 필요한 읽기(CPU·ANE 전력)는 앱 전체가 아니라 작은 보조 프로그램으로 분리합니다. 보조 프로그램을 허용하기 전에는 그 값을 '권한 필요'로 표시합니다.
- 온도·팬 센서(SMC)와 시스템 정보를 읽기 위해 App Sandbox를 끕니다. 개인용이라 App Store 배포는 고려하지 않습니다.
- fn은 macOS의 단축키 기능으로 등록할 수 없어서, fn + Space는 키보드 이벤트 탭으로 받습니다(손쉬운 사용 권한 필요). Space인지와 함께 누른 키만 확인하고 다른 입력은 그대로 흘려보내며 저장하지 않습니다.

  - [x] ANE 사용률: 직접 재는 값이 없음을 확인 → 사용 중 여부와 전력 W를 보여주고 %는 '측정 불가'로 표시
  - [x] 관리자 권한 보조 프로그램: 개인 팀 서명으로 등록·허용, root로 powermetrics 실행, XPC로 앱에 전달 ([진단 앱](Diagnostics/HelperProbe))
  - [x] 온도 센서·팬 RPM 읽기: 관리자 권한 없이 SMC로 읽음, CPU 최고·GPU 최고 센서 확정 ([진단 도구](Diagnostics/SensorProbe))
  - [x] 메모리 트래픽: 관리자 권한 없이 1초마다, 기기별로 읽힘 ([분석](Diagnostics/PowerProbe))
- [x] 화면 구현: 패널의 접기/펼치기, 상태 표시, 최근 그래프, 설정 창
  - [x] 화면 시안: 맨 위 3열 카드, 펼친 상세, 값 상태, 설정 창의 항목 색 선택
  - [x] 데이터 모델과 값 상태
  - [x] 패널 화면: 3열 카드, 눌러서 펼치기, 값 상태 표시
  - [x] 패널 그래프: 최근 30분 기록, 1·5·30분 선택, 재지 못한 구간은 선을 끊음
  - [x] 설정 창: 패널 단축키 바꾸기, 로그인할 때 열기, 항목 색 일곱 가지
- [x] 보조 프로그램 연결: CPU·ANE 전력을 패널이 열려 있으면 1초, 닫혀 있으면 10초마다 받음. 설정 창의 '보조 프로그램' 탭, 패널의 허용 단추 (통합 단계에서 앞당김)
- [x] 네트워크 기록: 속도, 오늘·이번 실행 누적, 날짜별 저장(같은 날 다시 켜면 이어서 셈), 잠자기·자정 처리
- [x] 통합: 실제 수집기 연결
  - [x] CPU·GPU 사용률: E·P 묶음별 평균과 코어별 값(OS CPU 시간), GPU Device Utilization
  - [x] GPU 전력, ANE 사용 중 여부, DRAM 트래픽(합계·읽기·쓰기·기기별): 관리자 권한 없이 IOReport로
  - [x] 메모리: 사용량(활성 상태 보기의 '사용된 메모리'와 같은 정의)·압력·압축·스왑

## 폴더 구조

```
MonitorTool/      앱 코드
  App/            시작점, AppDelegate
  Model/          측정값과 값 상태, 화면이 보는 저장소
  Collection/     값을 모으는 일정(패널을 열면 1초, 닫으면 항목에 따라 5·10·30초)과 수집기(CPU·GPU 사용률, IOReport, 메모리, 온도·팬(SMC), 배터리, 네트워크)
  Helper/         보조 프로그램 켜기·끄기와 XPC 연결
  Appearance/     항목과 항목 색 설정
  MenuBar/        메뉴 막대 아이콘
  Panel/          사이드 패널 창과 화면
    Cards/        기본 화면의 카드
    Details/      눌렀을 때 펼쳐지는 상세
    Charts/       최근 기록 그래프
    Components/   여러 화면이 함께 쓰는 조각
  Settings/       설정 창 (일반·모양·보조 프로그램)
  Support/        전역 단축키(fn + Space 이벤트 탭, 직접 정한 조합)와 단축키 설정, 숫자 표시 형식
MonitorToolHelper/ 관리자 권한 보조 프로그램 (powermetrics로 CPU·ANE 전력을 재서 앱에 전달)
Shared/           앱과 보조 프로그램이 함께 쓰는 XPC 약속
LaunchDaemons/    보조 프로그램의 launchd 설정 (빌드할 때 앱 안으로 복사)
Diagnostics/      기술 검증용 진단 앱
docs/             설계 문서
```

## 개발 환경

- MacBook Pro (M1 Pro), macOS 27
- Xcode 27, Swift, SwiftUI + AppKit
- 외부 라이브러리 없음
