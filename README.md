# MonitorTool

macOS 메뉴 막대에 상주하는 개인용 시스템 모니터링 앱입니다. 단축키나 메뉴 막대 아이콘으로 화면 오른쪽에 실시간 패널을 꺼내 보고, 알림 센터에서도 같은 수치를 확인하는 것을 목표로 합니다. [Monit](https://mmonit.com/widget/)의 빠르게 확인하는 사용 경험을 참고했습니다.

> 개발 중입니다. 전체 설계는 [docs/PROJECT_DESIGN.md](docs/PROJECT_DESIGN.md), 기능별 설계는 [위젯](docs/WIDGET_V2.md)·[팬 제어](docs/FAN_CONTROL.md)·[디스크 I/O](docs/DISK_IO.md)·[디스크 활성 시간](docs/DISK_ACTIVE_TIME.md) 문서에 있고, 단계별 작업 과정을 커밋 기록으로 남기고 있습니다.

## 보여줄 정보

| 항목 | 기본 화면 | 펼치면 |
|---|---|---|
| CPU | E-core·P-core 사용률, CPU 전력 W | E/P 사용률·전력 그래프, 코어별 정보 |
| GPU | 사용률, GPU 전력 W, GPU 메모리(앱들이 GPU용으로 할당한 합계) | 사용률·전력·메모리 그래프 |
| ANE (Neural Engine) | 사용 중 여부, 전력 W (사용률 %는 macOS에서 잴 수 없어 보여주지 않음) | 전력·메모리 트래픽 그래프, 켜져 있을 때의 ANE 온도 |
| RAM | 사용량/전체, 사용률, 메모리 트래픽(합계와 CPU·GPU·ANE별 GB/s) | 사용량·트래픽 그래프, 읽기·쓰기, 메모리 압력, 압축, 스왑 |
| 온도·팬 | CPU·GPU 최고 온도, 팬별 RPM | 센서별 온도, 팬별 RPM 그래프, 팬 제어(시스템 자동·고정 RPM) |
| 배터리 | 잔량, 충전/방전 상태, 순전력 W, 예상 시간 | 순전력 그래프, 성능 상태, 최대 용량, 사이클 수 |
| 디스크 | 물리 디스크별 읽기·쓰기 속도, 활성 시간 % | 디스크 고르기, 활성 시간·속도·동시 요청 그래프, 응답 시간·초당 작업, 오늘 누적, 오류·재시도, SMART(지원하는 디스크만) |
| 네트워크 | 업로드·다운로드 속도, 오늘 누적 | 그래프, 오늘·이번 실행 누적, 인터페이스별 수치 |

측정 전이거나 읽지 못한 값은 0으로 채우지 않고 상태(준비 중·미지원·권한 필요·오류·오래됨)로 표시합니다.

## 화면

- **실시간 패널**: 메뉴 막대 아이콘이나 단축키(기본 fn + Space, 설정에서 끄거나 직접 정한 조합으로 바꿀 수 있음)로 화면 오른쪽에서 꺼냅니다. 맨 위 카드에 CPU·GPU·ANE를 나란히 보여주고, 수치를 누르면 그 아래로 그래프와 상세 정보가 펼쳐집니다. 고정 단추를 켜면 다른 곳을 눌러도 닫히지 않습니다. 설정에서 항목 순서(끌어서 옮기기), 패널 배경(Liquid Glass 유리·색조·흐림)과 글자 색, 막대와 그래프의 항목별 색(여덟 가지)을 바꿀 수 있습니다.
- **알림 센터 위젯**: 요약 위젯(중간·큰)은 패널과 같은 카드 모양으로 핵심 수치를, 그래프 위젯 6종(작은)은 항목별 최근 10분 그래프를 보여줍니다. 앱이 App Group 공유 파일 하나에 10초에 한 번까지 값을 쓰고 위젯에 다시 그려 달라고 요청합니다. 원래는 누르면 위젯 높이가 늘어나는 방식을 원했지만, 이를 위한 구형 Today 확장이 macOS 27에서 등록되지 않는 것을 [진단 앱](Diagnostics/TodayWidgetProbe)으로 확인하고 WidgetKit으로 바꿨습니다. ([설계](docs/WIDGET_V2.md))
- **팬 제어**: 패널의 온도·팬 펼침과 설정 창 '팬' 탭에서 팬마다 시스템 자동·고정 RPM(이름 붙인 프리셋)·정지를 고르고, 정한 시간이 지나면 시스템 제어로 돌아갑니다. SMC 쓰기는 관리자 권한 보조 프로그램이 하고, 열 압력이 보통을 벗어나거나 CPU·GPU 최고 온도가 95 °C 이상이면 바로 시스템 제어로 돌려 놓습니다. 앱이 꺼지거나 Mac이 잠들 때도 시스템 제어로 돌아갑니다. ([설계](docs/FAN_CONTROL.md))

## 처음 실행할 때

1. 개발 중에는 Xcode에서 **MonitorTool** 스킴으로 실행합니다. 늘 쓰는 앱은 `bash Scripts/build-app.sh`로 Release 빌드를 응용 프로그램 폴더에 설치합니다(위젯 등록까지 함께 해요. Archive 안의 예전 위젯 확장이 위젯 목록을 가린 적이 있어서 Xcode의 Archive는 쓰지 않습니다). 보조 프로그램(`MonitorToolHelper`)과 위젯 확장은 함께 빌드되어 앱 안에 들어갑니다. 개인 팀으로 서명하므로 Xcode에 Apple ID가 로그인되어 있어야 합니다.
2. 패널 아래 **CPU·ANE 전력: 보조 프로그램 허용하기**를 누르면 시스템 설정의 로그인 항목 화면이 열립니다. '백그라운드에서 허용'에서 MonitorTool을 켜면 CPU·ANE 전력이 나타나고 팬 제어를 쓸 수 있습니다.
3. 끄려면 설정 창의 **보조 프로그램** 탭에서 '끄기'를 누릅니다. 앱을 지우기 전에도 꺼 두세요.
4. fn + Space로 패널을 열려면 처음 실행할 때 뜨는 macOS 창(또는 설정 창 '일반'의 **허용하기**)에서 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용의 MonitorTool을 켭니다. 권한 없이 쓰려면 설정 창 '일반'에서 '직접 정한 조합'(기본 ⌃⌥M)을 고르고, 단축키가 필요 없으면 스위치로 끕니다.

## 설계 원칙

- 수집은 메인 앱 한 곳에서 하고, 패널과 위젯은 같은 데이터를 봅니다.
- 관리자 권한이 필요한 일(CPU·ANE 전력 읽기, 팬 속도 쓰기)은 앱 전체가 아니라 작은 보조 프로그램으로 분리합니다. 보조 프로그램을 허용하기 전에는 그 값을 '권한 필요'로 표시합니다.
- 온도·팬 센서(SMC)와 시스템 정보를 읽기 위해 App Sandbox를 끕니다. 개인용이라 App Store 배포는 고려하지 않습니다.
- fn은 macOS의 단축키 기능으로 등록할 수 없어서, fn + Space는 키보드 이벤트 탭으로 받습니다(손쉬운 사용 권한 필요). Space인지와 함께 누른 키만 확인하고 다른 입력은 그대로 흘려보내며 저장하지 않습니다.

- [x] 네트워크 속도 단위: 설정 창 '일반 > 단위'에서 MB/s(바이트)·Mbps(비트, bps·Kbps·Mbps·Gbps 자동) 고르기, 패널과 위젯 모두, 기본 Mbps. 그래프 눈금은 고른 단위에서 깔끔한 값(10 Mbps 등), 누적량·디스크는 바이트 그대로 (사용자 요청, [#1](https://github.com/seungheon8086/MonitorTool/issues/1)). 패널 '네트워크 자세히' 기간 단추 아래의 `MB/s │ Mbps` 단추로도 바꿀 수 있고 설정 창과 같은 값 ([#3](https://github.com/seungheon8086/MonitorTool/issues/3))

## 폴더 구조

```
MonitorTool/        앱 코드
  App/              시작점, AppDelegate
  Model/            측정값과 값 상태, 화면이 보는 저장소, 팬 이름
  Collection/       값을 모으는 일정(패널을 열면 1초, 닫으면 10초·배터리 30초, 화면이 꺼지면 30초)과 수집기
                    (CPU·GPU 사용률·GPU 메모리, IOReport, 메모리, 온도·팬(SMC), 배터리, 디스크·SMART, 네트워크)
  Helper/           보조 프로그램 켜기·끄기와 XPC 연결
  Fan/              팬 제어 상태·프리셋과 입력 조각
  Widget/           위젯 공유 파일 쓰기
  Appearance/       항목, 항목 색, 패널 배경·글자 색·항목 순서 설정
  MenuBar/          메뉴 막대 아이콘
  Panel/            사이드 패널 창과 화면
    Cards/          기본 화면의 카드
    Details/        눌렀을 때 펼쳐지는 상세 (팬 제어 포함)
    Charts/         최근 기록 그래프
    Components/     여러 화면이 함께 쓰는 조각
  Settings/         설정 창 (일반·패널·모양·보조 프로그램·팬)
  Support/          전역 단축키(fn + Space 이벤트 탭, 직접 정한 조합)와 단축키 설정, 숫자 표시 형식, 창 흐림
MonitorToolHelper/  관리자 권한 보조 프로그램 (powermetrics로 CPU·ANE 전력, SMC 쓰기로 팬 제어와 안전장치)
MonitorToolWidget/  알림 센터 위젯 확장 (요약 위젯, 그래프 위젯 6종)
Shared/             앱과 보조 프로그램이 함께 쓰는 XPC 약속, 팬 제어 요청·상태, SMC 연결
WidgetShared/       앱과 위젯이 함께 쓰는 공유 파일 형식
LaunchDaemons/      보조 프로그램의 launchd 설정 (빌드할 때 앱 안으로 복사)
Scripts/            Release 빌드·설치(build-app.sh), 안 쓰는 코드 검사(periphery.sh)
Diagnostics/        기술 검증용 진단 앱·도구와 측정 결과
docs/               설계 문서
```
