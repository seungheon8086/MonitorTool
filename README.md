# MonitorTool

macOS 메뉴 막대에 상주하면서, 단축키 한 번으로 화면 오른쪽에 시스템 상태 패널을 꺼내 보는 개인용 모니터링 앱입니다. [Monit](https://mmonit.com/widget/)의 슬라이드 패널 방식을 참고했습니다.

> 개발 중입니다. 단계별 작업 과정을 커밋 기록으로 남기고 있습니다.

## 보여줄 정보

| 항목 | 내용 |
|---|---|
| CPU | 전체·코어별 사용률 (성능/효율 코어 구분) |
| 메모리 | 사용량, 압축, 스왑, 메모리 압력 |
| GPU | 사용률, GPU가 쓰는 메모리 |
| 배터리 | 실시간 충·방전 전력(W), 완충·방전까지 남은 시간, 배터리 상태 |
| 네트워크 | 실시간 업로드·다운로드 속도, 누적 사용량 |
| 온도·팬 | CPU·GPU 온도, 팬 속도 |
| 상위 프로세스 | CPU·메모리를 많이 쓰는 프로세스 |

## 설계 메모

### 위젯이 아니라 패널인 이유

macOS 알림 센터 위젯(WidgetKit)은 시스템이 갱신 횟수를 하루 단위 예산으로 제한합니다. 자주 보는 위젯도 하루 40~70회, 대략 15~60분 간격이라 초 단위 수치를 보여줄 수 없습니다. 그래서 알림 센터처럼 보이는 자체 패널을 만들었습니다.

### 구조

- **앱 형태**: Dock 아이콘 없이 메뉴 막대에 상주 (`LSUIElement`)
- **패널**: 포커스를 뺏지 않는 `NSPanel` + Liquid Glass(`NSGlassEffectView`) + SwiftUI
- **단축키**: Carbon `RegisterEventHotKey` (손쉬운 사용 권한 불필요)
- **데이터 흐름**: 수집기(항목별) → 저장소(최신값·최근 기록) → SwiftUI 카드
- **갱신 주기**: 패널이 열려 있으면 1초, 닫혀 있으면 메뉴 막대 수치와 누적 기록만 느리게 갱신

### App Sandbox를 끈 이유

온도·팬 센서(SMC)와 다른 프로세스 정보는 샌드박스 안에서 읽을 수 없습니다. 개인용이라 App Store 배포는 고려하지 않았습니다.
